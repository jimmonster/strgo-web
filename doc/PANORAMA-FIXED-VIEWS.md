# 同一空间的固定机位全景

适用 `/360/`，用户只需上传一张示例图或输入文字，选择 3 或 5 个机位，点击生成，然后在 HTML 页面点击机位切换。每个机位支持原有拖动环顾、缩放、触屏与全屏。此功能没有自由行走操作。

## 空间一致性的实现

本实现不逐机位调用 Image2。独立生成图片即使使用相同提示词和参考图，也不能据此保证三维位置、比例和遮挡一致。

World Labs 公开的 [Atlas 技术说明](https://www.worldlabs.ai/blog/atlas) 描述了共享空间上下文、相机几何以及新视图与几何的联合生成；这能指导架构，但不能据此声称复现了其未公开的训练模型。本仓库使用公开的 [World API](https://docs.worldlabs.ai/api/world-generation-examples) 获取一份持久三维场景，而不是实现或训练 Atlas。

处理流程：

1. 文字或示例图提交到服务器，同一项目只调用一次 World Labs 世界生成；上游权限固定为 `public: false`。
2. 服务端保存任务编号，后续只轮询已有任务。生成成功后获取一份 Gaussian splat 场景，并在私有存储中缓存、记录 SHA-256。
3. 浏览器的临时渲染 frame 加载这一份场景，在同一个坐标系设置 3 或 5 个固定相机位置。每个位置使用同一个 splat 场景、径向排序及六个立方体面，输出 2048 × 1024 等距柱状投影图片。
4. 常规全景浏览器只切换这些已输出的图片；切换保留 yaw、pitch 和 FOV。返回已有机位直接复用同一个 Blob，不再次调用模型。重开项目读取已缓存的共同场景再输出机位。

因此，机位之间的空间一致性来自**共同场景和确定的相机投影**。生成的共同场景本身可能有几何缺陷或对输入中不可见区域的推测；本实现不把它描述成实测建筑或真实场景的精确重建。当前近邻机位固定在原始相机高度，水平偏移为 `0 / -0.45 / +0.45 m`；5 机位再加 `-0.9 / +0.9 m`。密闭狭小空间仍可能发生相机穿入表面，不提供碰撞导航或自动安全机位规划。

尺度使用返回的 `metric_scale_factor`；原始相机原点保持不变，避免凭空设置眼高。渲染遵循 [Marble SPZ 坐标说明](https://docs.worldlabs.ai/api/rendering-spz)，通过 X 轴旋转 180° 转换 OpenCV 方向。这里不做贴地行走，因此不移动原始相机来套用地面对齐。

## 服务配置

沿用共享账号与生图服务，在服务端环境配置：

```dotenv
PANORAMA_WORLD_API_KEY=供应商密钥
PANORAMA_WORLD_MODEL=marble-1.1
PANORAMA_WORLD_DAILY_LIMIT=3
```

密钥只进入服务端向 `api.worldlabs.ai` 发出的请求，不返回浏览器或写进 HTML。未配置密钥时页面明确显示不可生成，不退回到独立文生图后声称空间一致。空间模型计费独立于原生图张数额度；普通成员默认每天 3 个空间，管理员不限。一个项目无论 3 或 5 机位都只预留一次空间额度。失败、结果未知也保留用量，按北京时间零点重置。

现有单张文生图继续使用当前账号已配置的模型，包括兼容接口的 Image2。若需要 Image2 的视觉效果，可以先生成单张全景，再点击固定机位面板的“以当前全景为示例”，由空间模型基于它建立共同场景。整个过程中不需要用户编辑几何或相机。

普通照片通过“上传示例图”进入，按非全景输入处理；“以当前全景为示例”使用已验证的全景输入。参考图复用工作台的浏览器压缩，最长边 4096、最多 2 MB；服务端校验实际格式及编码，任务提交前加密暂存，提交后清除。

## 接口、恢复与私有数据

- `GET /api/image/panorama-tours`：当前账号的最近 20 个项目、是否可生成及独立空间额度。
- `POST /api/image/panorama-tours`：`scene`、可选 `referenceImage`、`isPano`、`cameraCount`（3/5）、`requestId`。
- `GET /api/image/panorama-tours/<id>`：读取并更新已有空间任务，返回同源场景地址及固定相机列表。
- `GET /api/image/panorama-tours/<id>/splat`：读取私有场景缓存；浏览器不能传入任意外部 URL。

全部接口复用会话、Origin、CSRF 和账号状态检查。即使管理员也不能通过本接口读取别人的空间。返回值不暴露上游密钥、签名 URL 或私有世界 ID；上游结果加密保存在 SQLite，随现有数据库备份。场景缓存使用现有私有存储和文件校验。

同一账号的 `requestId` 唯一，重试返回已有项目，不重复占额或调用生成。服务启动只恢复排队任务；若中断发生在外部提交阶段，将任务标为 `unknown` 并清除参考图，不自动重发付费请求。已确认的远程任务可继续 GET 轮询。前端刷新可从项目列表恢复，sessionStorage 只保留项目或请求编号，不保存参考图。

页面隐藏、切换账号或离开时移除临时渲染 frame、图片 Blob、参考图预览和私有项目列表，迟到结果无权更新新会话。已输出全景仅在当前页面内存中，只有用户点击“下载当前机位全景”才下载文件；不把它们复制成不受账号保护的本地全景条目。

## 构建与验证

`@sparkjsdev/spark 0.1.10` 与隔离的 `three-spatial 0.178.0` 被锁定并准备为本地 vendor 模块；原站 Three.js 仍为 0.160.1。所有新三维渲染运行在短生命周期的同源 frame，输出完成后销毁。正常全景展示继续按需渲染，不持续执行空间模型或后台三维循环。

正式发布还需应用 `deploy.sh` 的 Nginx 配置更新：主文档允许同源 frame，只有精确路径 `/360/fixed-render.html` 允许同源嵌入、Blob worker、内嵌 WASM 数据读取与 `wasm-unsafe-eval`。其他页面继续禁止嵌入，也不允许普通 JavaScript 的 `unsafe-eval` 或内联脚本。内部页面不注入共享导航或字体；vendor 准备固定选用 Spark 已有的 CSP 安全 PLY 解析器，不执行动态编译探测。浏览器回归实际加载部署脚本中的两条 CSP 验证该隔离边界。场景文件最多 24 MiB，优先 500k splats，下载失败或过大时可读取同一世界的 100k 版本，不会重新调用世界生成。

```bash
npm ci
npm run build:production
python3 -m unittest tests.test_panorama_tours -v
npm run test:360:browser
```

后端回归覆盖共同空间仅提交一次、3/5 个实际不同坐标、加密参考图、缓存校验、并发幂等、独立额度、账号隔离、Origin/CSRF，以及中断不自动重生成。浏览器使用可复现的合成 Gaussian splat 房间，实际执行 WebGL 的六面投影和 2:1 输出；检查机位图片不同、返回机位像素不变、保留朝向、下载、刷新重开、五语、小屏和账号变化。真实 HTTP/SQLite 回归使用相同接口与测试供应商，覆盖任务入队、后台处理和私有场景读取。

上述测试不调用真实收费空间模型。真实供应商账号权限、额度、返回场景质量、SPZ 格式和复杂室内机位，需要在配置后另行验收；不能把测试场景记为真实生成结果。
