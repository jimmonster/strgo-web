# 全站统一后台需求

日期：2026-10-23。适用根主站 `src/admin/`、共用账号服务 `image_service/`。用户已确认全站统一管理范围；与 [功能清单 F02](FEATURE-BACKLOG.md) 同步。

## 入口与范围

`/admin/` 提供适配手机与桌面的管理入口，使用已有共享账号登录。未登录展示登录，普通成员明确拒绝。导航包括概览、账号、邀请码、社区、生图额度、任务、审计及 AI 管理。模型/节点/预算/AI权限复用 `/admin/ai/`，Workflow 继续使用独立域名管理员登录。

1. 概览显示真实账号、活跃会话、社区帖子、图片及音频数量/字节、按模块任务状态、存储可用性和备份摘要；不触发模型或探测远程服务。
2. 账号列表支持用户名搜索和有界分页，显示角色、状态、创建时间、会话数；允许停用/恢复、修改角色、撤销指定账号全部登录。停用与降权及时撤销现有共享及 Workflow 会话。禁止停用自己、撤销自己的所有会话和移除最后一名启用管理员。
3. 邀请码只在创建时显示原文，列表显示时间、状态、使用者；允许撤销未使用的邀请码。默认新建普通成员邀请，不发放绕过首位管理员约束的邀请码。
4. 社区列表支持分类、搜索与分页，复用已有置顶、取消置顶、删除和所有者保护行为；执行删除需明确确认。
5. 统一编辑既有普通成员每日生图张数策略，显示 `null` 不限、`0` 暂停语义；预装灵感和全员图片治理提供现有管理入口。
6. 任务页按生图、AI、Workflow 展示状态、时间与所有者等元数据，不展示私人提示词、歌词或对话；不增加自动重生成或未知任务强制解锁。
7. 审计记录后台账号/邀请/额度/社区操作的操作者、目标、动作、时间与最少必要变化；只读、有界分页，不包含凭据或正文。

## 权限和持久化

所有管理 API 位于 `/api/image/admin/`，逐请求验证共享会话与管理员角色，写入还须同源和 CSRF。只隐藏页面按钮不算权限控制。追加建表兼容现有账号；账号状态与审计随 SQLite 备份，恢复时仍执行现有会话撤销。现有 AI 停用账号与全站停用规则一致，恢复账号不得绕过 AI 自身的模块禁用状态。

角色/状态修改与最后管理员检查在同一写事务中；角色修改后同步原有加密账号恢复清单，避免 reindex 恢复成旧角色。持久化失败保留明确反馈和可重试行为。

## 实现与使用

已实现：`src/admin/`、`image_service/admin.py`、追加式 `account_controls` / `admin_audit` 表。主站构建生成 `/admin/`，现有 `/admin/ai/` 保留；从生图「接口设置」的管理员区域、AI侧栏或直接地址进入。无需建立新账号系统。接口沿用现有 `/api/image/` 代理，无需额外开放端口。

账号修改携带 `revision`，版本冲突返回409并要求刷新；变更后撤销所有共享及Workflow会话。恢复全站账号不会自动解除原AI管理中的停用。密码重置、索引重建保留角色与停用状态。邀请码原文只展示一次；审计只保留邀请码散列标识。任务摘要不返回私人提示词/歌词/对话和配置密钥。

登录签发会话前在写事务中校验账号版本；管理员撤销会话也提升版本，旧的在途密码校验不能重新建立会话。改密在同一事务中重新核对当前会话、版本与账号状态，按最新账号记录保存加密清单并替换会话。CLI重置密码同样串行保存账号与撤销会话，避免覆盖并发角色/状态修改。撤销后重新发起的正常登录仍可使用。

开发验证：`python -m unittest tests.test_admin -q`、`node --test tests/admin.test.mjs`、先构建再 `node tests/admin-browser.mjs`。浏览器脚本启动临时账号服务，仅监听回环8092；需该端口空闲，设置 `STRGO_PYTHON` 指向Python，Chrome可用 `CHROME_PATH` 指定。临时演示账号只在隔离夹具中存在，生产入口不会加载夹具。
