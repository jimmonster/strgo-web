## 本轮实现

| 模块 | 交付 |
| --- | --- |
| AI 断线恢复 | 恢复同一个已有任务；UTF-8/CRLF 事件流、无数据超时与会话失效反馈；恢复历史不重复插入消息 |
| AI 显式重试 | 失败/中断/取消消息先回填输入框；确认后重新报价、创建新任务；保存原任务关联，校验所有者、会话和终态，沿用幂等与额度控制 |
| 助手状态 | 切换会话或移除组件后拒绝迟到结果；应用建议期间保留人工新编辑；模型名称保持原样，部署方式随语言切换 |
| 音乐草稿 | 仅切换时长或人声/纯音乐也触发防抖自动保存；连续保存使用最新表单版本 |
| 节点调度 | 按服务端状态反转排空标志；操作时禁用按钮，连续排空/恢复回归 |
| 卧室 | 电脑工作区视角、三维电脑点击进入真实终端路由、键盘可访问链接；拖动或多指手势不误触 |
| 舞台 | 默认静音；主动开启的本地原创节奏、音量、暂停/恢复/重置/离开清理；不下载音频或请求模型 |
| 五语与搜索 | 补齐 POLYVERSE 长篇说明/搜索摘要、MEOW 清单、AI 固定标签、助手模型状态、装饰与新增场景操作；配置章节进入五语本地搜索 |
| 渲染错误反馈 | WebGL 初始化失败时给出明确状态，禁用失效场景控件并保留可用导航 |
