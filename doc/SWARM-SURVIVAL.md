# 虫潮生存

适用模块：`apps/swarmera/`。2026-11-16 新增原生目录路由 `/swarmera/survival/`。虫族首页的主按钮、独立入口卡、桌面和移动导航，以及原有交互战场都可进入；原有三维展示保留。

## 玩法

采用俯视战场和 Canvas 2D 绘制。玩家驾驶防线机甲移动并持续自动射击，默认锁定最近敌人，也可切换鼠标瞄准。目标是生存至少五分钟，并击杀全部已出现的大蜈蚣。最终变异体在第 240 秒出现，未击杀时战斗会继续，不会仅按倒计时结束而判胜。

- 飞天蜘蛛持续从玩家视野外生成，有普通与重甲变种。每 30 秒推进波次并提高密度；狂潮模式的生成率为标准模式的 1.7 倍，最多 420 个敌方单位同时存活。
- 普通变异大蜈蚣每 45 秒出现一次，拥有 14 节身体；最终变异体有 23 节。所有身体节都参与子弹、脉冲和接触判定，共享生命值。受伤到一定程度后断尾并产生碎裂效果。
- 击杀掉落晶体，进入拾取范围后吸附。积累经验后暂停战斗，三选一升级：伤害、射速、多重射击、穿透、移速与拾取范围、装甲修复。
- 冲刺冷却 3 秒并提供短暂无敌；清场脉冲冷却 12 秒，作用于周围 330 个世界单位。
- 死亡和胜利均显示击杀、生存时间和等级。最佳击杀按标准 / 狂潮分开保存在当前浏览器；保存失败会提示并允许重新开始。

电脑使用 WASD / 方向键移动，空格冲刺，E 清场脉冲，P / Esc 暂停与继续。手机使用左侧摇杆和右侧技能按钮，默认自动瞄准。支持可选合成音效及浏览器全屏 API。

失去窗口焦点、切出页面或打开全站弹窗时暂停；升级界面不会在后台继续模拟。语言切换保留当前机甲属性、击杀和升级，并以暂停状态重新显示。页面离开会释放事件、动画循环、位图和音频资源。当前战局只保留在页面内存，刷新后重新开始；最佳击杀持久保存。

## 源码

| 文件 | 职责 |
| --- | --- |
| `apps/swarmera/src/survival/engine.js` | 不依赖 DOM 的固定 60 Hz 模拟、生成、空间网格碰撞、技能与升级 |
| `apps/swarmera/src/survival/renderer.js` | 缓存的程序化生物位图、地面、断节、弹道、脉冲、小地图和视口裁剪 |
| `apps/swarmera/src/survival/controller.js` | 键鼠和触摸输入、HUD、暂停、结算、语言重挂载与资源释放 |
| `apps/swarmera/src/survival/view.js` | 可静态生成的页面结构 |
| `apps/swarmera/src/survival/copy.js` | 简中、繁中、英文、日文、韩文文案 |
| `apps/swarmera/src/survival/styles.css` | 战场与响应式界面 |

子弹、晶体、特效分别设有 360、360、100 的存活上限。子弹使用线段命中检查避免高速穿越；同一枚子弹不会重复伤害同一条蜈蚣的多个身体节。生成点与玩家保持至少 560 的距离，靠近地图边缘时也不会直接贴身刷怪。实际设备帧率还需浏览器测量，实体上限不是性能承诺。

## 验证

在仓库根目录构建主站，再在应用目录构建和测试：

```bash
npm run build:production
cd apps/swarmera
npm run build
npm test
npm run test:survival:browser
```

本轮主站生产构建、29 路由应用构建和应用全部离线测试通过。其中新增 9 个模拟测试与 4 个 DOM / 绘制流程测试，覆盖跨帧率一致性、数百实体、身体命中与断尾、边缘生成、死亡与胜利、升级、真实控制器事件、语言重挂载、资源释放及存储异常。离线绘制测试使用 Canvas API 替身，验证调用和坐标有效性，不能替代实际像素、布局或触屏验收。

2026-11-16 当前受限环境的 HTTP 监听被 `listen EPERM` 拒绝，Chrome 启动也被 `setsockopt: Operation not permitted` 阻止，所以浏览器验收、截图、实际帧率与手机触屏验收尚未完成。可在允许本地端口和 Chrome 的开发机运行 `npm run test:survival:browser`，报告及截图输出至 `apps/swarmera/artifacts/survival-browser/`。该脚本覆盖键盘移动、技能、暂停、升级、密集战场、五语言保留进度、最佳记录和触摸摇杆；密集战场截图使用可复现的敌群布置夹具。

额外使用三个种子的避让策略运行完整五分钟模拟，均能通过最终变异体并进入胜利状态，用于确认流程可完成；这不等同于人工难度与手感验收。
