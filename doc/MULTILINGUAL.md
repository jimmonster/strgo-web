# 多语言适配

## 使用方式

STRGO 统一功能切换器旁边提供语言选择，支持简体中文（`zh-CN`）、繁体中文（`zh-TW`）、英语（`en`）、日语（`ja`）和韩语（`ko`）。门户主页的语言选择位于顶部；经典主页及其他使用共享导航的页面可在导航旁切换。选择立即生效，不清空表单或更改原有路由。设置保存在本浏览器的 `strgo:locale:v1`，同一来源的其他页面和标签页会使用该偏好；首次访问参考浏览器语言。Workflow 如果运行在独立域名，浏览器的同源隔离意味着其语言设置独立保存。

已适配统一门户、经典主页、卧室／舞台的主要文案和共享导航，以及论坛、生图工作台的主要静态界面、AI 工作区的公共导航、登录、概览和音乐表单的部分界面。入口目录支持以五种语言搜索已翻译的名称和描述。没有词条时保留原文；日语、韩语缺少专用词条时可回退英语。用户输入、提示词、模型输出、帖子、用户名、文件名及终端数据不会自动翻译，表单值和过滤器的内部值不随语言改变。

DREAMS 的英文／日文已与共享语言选择联动，其余三种语言暂保留原有内容；其他独立应用及终端服务有各自的文本与发布边界。目前这些独立应用的共享导航可以切换五种语言，但其场景正文、独立语言按钮、终端程序、AI 助手内部界面和后端错误消息尚未全部翻译，不能视为全站所有内容已经完成五语适配。未完成文本继续使用其原有语言。实际 ECS 上线须另按部署文档发布本次提交。

## 开发和扩展

- `src/shared/i18n.js` 负责语言识别、存储、切换事件、翻译和受控 DOM 更新。只在明确指定的界面区域处理已登记的固定文案；请保持用户数据区域的排除与 `data-strgo-user-content` 标记。
- `src/shared/translations.js`、`classic-copy.js`、`tool-copy.js`、`ai-copy.js`、`east-asian.js` 和 `traditional.js` 存放固定文案。新增界面文字时补全全部语言，保持筛选、路由和表单的稳定值独立于显示文案。不要使用翻译后的文本作为业务标识。
- 在独立应用上实现完整翻译，应修改 `apps/<应用名>/` 的权威源码，保留其用户数据和场景状态，按开发指南构建与同步；不能直接改生成目录。终端程序的 UI 与 Rust 发布另行验证。
- 运行 `npm run build:production` 与 `node --test tests/i18n*.test.mjs tests/hub.test.mjs`；涉及共享界面再运行根目录 `npm test`。真实浏览器需要验证小屏幕、无障碍标签、语言切换和跨页持久化。
