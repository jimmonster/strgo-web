# 多语言适配

## 使用方式

STRGO 统一功能切换器旁边提供语言选择，支持简体中文（`zh-CN`）、繁体中文（`zh-TW`）、英语（`en`）、日语（`ja`）和韩语（`ko`）。门户主页的语言选择位于顶部；经典主页及其他使用共享导航的页面可在导航旁切换。选择立即生效，不清空表单或更改原有路由。设置保存在本浏览器的 `strgo:locale:v1`，同一来源的其他页面和标签页会使用该偏好；首次访问参考浏览器语言。Workflow 创作台的界面和常见状态支持五语；如果运行在独立域名，浏览器的同源隔离意味着其语言设置独立保存。

已适配统一门户、经典主页、银河归档、更新页、作品详情、终端入口、卧室／舞台的主要文案和共享导航，以及论坛、生图工作台、AI 工作区的主要界面与常见状态提示。全站管理后台的主要界面和 AI 管理控制台的导航、表单与常用操作也已增加五语。DREAMS 的八章设计与电影正文、主题、独立语言选择和 404 页面支持五语；NEXUS 的目的地、星系、档案、设置及本地搜索支持五语。SWARMERA 原生渲染支持五语，文章、动作、交互状态与全站偏好联动；其本地意向与留言草稿仍由浏览器保存。

MEOW 的猫咪资料、常用界面、购物清单、本地档案和主要反馈已增加五语词条，POLYVERSE 的场景、控制、资料库、导入保存及部分文档已增加五语词条。两者使用共享导航切换并支持多语搜索。当前仍有 AI 管理控制台的部分数据视图、未登记的英文装饰文案、POLYVERSE 长篇技术文档片段及 MEOW 的少量次级提示可能显示原文，尚不能称为全站五语全部完成；新增界面应继续补齐五语词条与相应测试。

终端登录、工作区和会话的固定界面与主要状态支持五语，可独立切换并与同来源页面同步；后端返回的未知错误和远程程序输出保留原文。AI 助手的内置界面、预设提示和主要状态支持五语，用户草稿、对话和模型输出保持原样。入口目录和已登记的应用内容可以用译名搜索；未登记的文案保留原文，原有日语、韩语共享文案缺少专用词条时可能回退英语。用户输入、提示词、模型输出、帖子、用户名、文件名与终端数据不会自动翻译，表单值、筛选内部值和已保存作品名称不随语言改变。

各应用与终端服务仍有独立构建和发布边界；修改提交到 GitHub 后，实际 ECS 上线须按部署文档重新发布主站、相关独立应用和终端服务。
## 开发和扩展

- `src/shared/i18n.js` 负责语言识别、存储、切换事件、翻译和受控 DOM 更新。只在明确指定的界面区域处理已登记的固定文案。受保护内容区域中仅可对明确标记为 `data-strgo-ui-copy` 的固定标签进行翻译，必须保持用户数据区域的排除与 `data-strgo-user-content` 标记；静态提示使用 `data-strgo-static`，带用户内容或未知错误的提示不得加此标记。
- `src/shared/translations.js`、`classic-copy.js`、`tool-copy.js`、`ai-copy.js`、`east-asian.js`、`traditional.js` 以及各应用的 `*-copy.js`、`admin-copy.js`、`workflow-copy.js`、`legacy-copy.js` 和 `dynamic-copy.js` 存放固定文案；SWARMERA、终端和 AI 助手分别维护各自的词条。新增界面文字时补全全部语言，保持筛选、路由和表单的稳定值独立于显示文案。不要使用翻译后的文本作为业务标识。
- 在独立应用上实现完整翻译，应修改 `apps/<应用名>/` 的权威源码，保留其用户数据和场景状态，按开发指南构建与同步；不能直接改生成目录。终端程序的 UI 与 Rust 发布另行验证。
- 运行 `npm run build:production` 与 `node --test tests/i18n*.test.mjs tests/hub.test.mjs`；涉及共享界面再运行根目录 `npm test`。真实浏览器需要验证小屏幕、无障碍标签、语言切换和跨页持久化。
