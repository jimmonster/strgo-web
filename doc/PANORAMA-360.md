# 360° 全景模块

入口 `/360/`，注册表编号 `S09`。统一主页 `/hub/` 的目录、空间卡片、搜索、收藏及共享功能切换器使用同一条注册记录。经典主页、原有八个空间及其路由保留。

## 素材与渲染

默认素材是本次对话生成的《阳光下的大学校园广场.png》，原始尺寸 **1774 × 887**，严格 2:1。原图 SHA-256：`9783069871dc737a402c6dfed623bcaa9e6b93339c410165666a19f79c6ba796`。网站使用 `src/assets/panoramas/campus.webp`（质量 92，549398 字节），保留完整画面与原比例，没有裁切、拉伸或重绘。图片为 AI 生成，画面中的校名、人物与环境不代表真实学校实拍。源图细节、接缝和极区画质由原素材决定；浏览模块不会自动修复或重新生成图片。

沿用锁定的 Three.js 0.160.1，由 `prepare-vendor.mjs` 准备本地模块及许可证，不请求 CDN。相机在反向球体中心，使用球体 UV 映射等距柱状投影，纹理与输出均为 sRGB，无灯光与色调映射干扰。渲染按输入、尺寸和图形恢复事件触发，静止时不持续运行 RAF，也不自动旋转。默认视角 yaw/pitch 为 0°，垂直视野 75°；视野限制 35°–100°，俯仰限制 ±85°。

复用 `content/app-registry.json` 的视觉 token、共享字族、图标和五语切换。源码位于 `src/panorama/`，根构建复制到 `dist/360/`，输出真实目录索引、canonical 与 sitemap；支持直接访问、刷新及末尾斜杠重定向。构建摘要包含该模块源码，正式构建要求本地 Three.js 存在。

## 交互与图片导入

- 鼠标拖动与单指触摸旋转；滚轮、双指捏合和按钮缩放。
- 画面获得焦点后，方向键旋转，＋/− 缩放，R 重置，F 全屏。控件保留可见焦点与 44 px 点击区域。
- 支持 Fullscreen API；不支持或被拒绝时进入占满视口的页面全屏，Esc 或退出按钮恢复。手机适配横竖屏和安全区。
- 本地导入 JPG、PNG、WebP，最大 40 MiB，解码上限 16384 × 8192，宽高比允许约 1% 导出误差。比例不符、图片损坏或加载失败时显示错误，保留当前成功画面。本地文件保存在当前浏览器，不上传或写入服务端。
- 大图按显卡纹理上限等比降采样，最长边额外限制为 8192；原始文件不改变。更换纹理时释放旧 GPU 资源，解码结束或取消时回收对象 URL；切换图片时仅最新请求可以更新画面。
- 浏览器无法创建 WebGL 时保留静态校园图与错误提示；纹理加载失败可重试。图形上下文丢失时暂停控件，恢复后重建纹理状态。

普通宽幅照片即使比例接近 2:1，也不保证具备球面全景的正确投影和无缝边缘。

## 全景条目

有效图片载入后自动创建独立条目，重复导入同一文件也会创建新条目；从“我的全景条目”再次打开不会重复创建。默认标题使用文件名或 AI 作品标题，内容留空。卡片提供打开、编辑和删除操作；标题必填、最多 160 字符，内容最多 5000 字符，允许多行。标题与内容通过 `textContent` 显示，界面五语切换不会改写用户文字。编辑当前画面的条目会同步更新画面下方的标题和内容；取消编辑保留原值。

`src/panorama/store.js` 使用 IndexedDB 数据库 `strgo-panorama-items`（版本 1），`items` 保存元数据和本地缩略图，`files` 保存本地原文件。列表读取不会加载所有原图；保存和删除在同一事务内操作两张表，失败或取消时不会留下孤立文件或半成品条目。只有事务完成后才显示“已保存新条目”。浏览器禁止存储或空间不足时保留当前预览、提示未保存并提供“重试保存”。刷新列表会重新读取浏览器数据，刷新页面后可重新打开和继续编辑。

删除需确认；取消保留条目，确认后移除条目及其本地文件，正在浏览该条目时返回校园全景。校园默认图不属于用户条目。条目仅保存在当前浏览器，清除网站数据会移除，暂不提供服务器备份或跨设备同步；本地图片在该浏览器内可直接访问。

AI 条目仅保存原作品 ID、账号 ID、标题、内容和尺寸，不持久化私有图片、缩略图或签名 URL。列表仅显示当前账号的 AI 条目，页面隐藏或切换账号时移除私有卡片并关闭、清空私有编辑和删除对话框。再次打开使用原有同源图片接口，重新验证会话及账号；权限丢失、原图删除或资源不可用时显示错误，不复制出另一张私有图片。编辑和删除 AI 条目仅影响浏览器中的条目记录，不修改或删除 AI 原作品。

## STRGO AI 生图

全景页的“从 AI 作品导入”读取现有 `GET /api/image/session` 和 `GET /api/image/hub/assets?source=image&limit=18`，按返回的 cursor 加载更多。服务端始终按当前账号筛选作品，不请求 `scope=all`，不新增数据表、上传接口或公共分享权限。作品标题通过 `textContent` 显示，用户提示词、名称和本地文件名不随界面翻译。

生图工作台的作品预览增加“360° 浏览”，使用 `/360/?image=<32位图像ID>`。页面仅接受规范 ID，自己构造同源 `/api/image/assets/<id>`，不接受任意 URL、外域链接或签名地址。图片沿用服务端 Cookie 与原有资源权限；解码前后验证当前身份。未登录、403、删除或过期资源会显示明确错误，不会公开作品。

关闭作品选择会取消请求并移除缩略图。私有画面在页面隐藏或离开时清除，在重新获得焦点时检查账号变化；账号失效或变化后回到校园图，不让旧账号的作品进入新会话。私有图片读取使用 `cache: no-store`，不持久化图片内容；条目元数据的范围见上节。

“前往 AI 生图”使用 `/image-playground/?panorama=1`，登录后仅预填 **2048 × 1024** 和校园全景提示词，不覆盖已有的 job/reuse 深链，不自动创建或重试生成任务。可修改提示词后手动生成，实际模型需支持该尺寸与全景投影。生成后打开作品预览，点击“360° 浏览”；导入仍按实际解码尺寸检查，不能依赖请求参数宣称输出已是全景。

## 验证

```bash
npm ci
npm run build:production
npm test
npm run test:360:browser
python3 scripts/sync-hub-docs.py --check
```

浏览器脚本使用 `STRGO_CHROME` 或 `CHROME_PATH` 指定 Chrome，也可使用 Playwright 已安装的 Chromium。它启动本地静态预览，账号与作品接口使用测试响应，不触发真实模型或线上写入。覆盖实际 WebGL 画面、拖动、触摸与捏合、键盘、全屏及后备全屏、本地导入、损坏和错误比例、AI 分页与深链、账号变化、权限拒绝、页面隐藏清理、迟到响应、上下文恢复、五语、门户与共享导航。条目回归还覆盖独立新增、实际 IndexedDB 持久化、标题/多行内容编辑、取消、刷新恢复、再次打开不重复创建、删除及文件清理、AI 引用隔离与权限检查、事务中途存储失败回滚和重试。截图与 JSON 报告写入忽略目录 `artifacts/panorama/`。

根 Node 测试验证视角数学、格式/尺寸边界、ID 与草稿路由及五语搜索；Python 测试在两种主页配置下检查真实构建输出、默认素材、共享导航和 sitemap。已有生图交互回归继续覆盖登录、生成、删除及任务复用。Linux CI 的浏览器阶段加入该回归，`verify.mjs --browser` 也包含它。

提交源码和测试不等于发布；此功能随主站未来获授权的构建发布提供，无需修改生产代理或账号服务。
