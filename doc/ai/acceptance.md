# 验收记录与后续顺序

这份记录区分已实现、已自动验证与待实际环境验证，不能把模拟音频/模型作为真实 AI 能力证据。

## 已完成的代码范围

| 阶段 | 交付 |
| --- | --- |
| P00 宿主适配 | 共用原有账号、Python、SQLite、构建、代理和存储；记录于 implementation.md |
| P01–P04 权限与配置 | 模块/模型授权、到期、停用、TOTP 二次验证、加密配置、报价与原子额度/预算预占 |
| P05–P07 任务与对话 | 持久化任务、唯一结算、幂等、重放、部分回复、停止、独立及绑定表单的对话组件 |
| P08 音乐助手 | 严格补丁校验、差异预览、保存人工修改后校验版本、应用与生成分开 |
| P09–P10 音乐工作台 | 本地/在线适配、异步进度、暂存恢复、私有音频、播放/下载、复用原任务参数 |
| P11–P12 管理与维护 | 权限申请、模型/节点、预算/对账、审计、保留期、独立删除重放与 CLI |
| P13 自动化验证 | 前端接口契约、后端事务/恢复/隔离、真实本机 HTTP SSE/Range、原有功能回归 |
| P14 交接 | 部署顺序、接口、扩展契约与验收差距 |

原设计中独立节点 agent/fencing 采用当前部署约束下的中央锁保守实现，尚不能作为多调度器共享 GPU 的分布式网关。该能力扩展必须按 implementation.md 的约束先补代理。

## 自动验证覆盖

测试入口：`npm run test:ai`、`npm test`、`npm run build:production`。实际运行结果以本次提交交接信息及 CI 输出为准。

2026-10-22 在合并仓库最新 ComfyUI 提交 `5dd523a` 后验证：`npm run build:production` 成功；`npm test` 的 **73 项 JavaScript 测试、171 项 Python 测试全部通过**。包含新增 AI 契约测试、100 次竞争一次剩余额度的事务测试、模拟跨北京时间午夜结算、原有及新增 ComfyUI/Workflow 测试。JS/CSS 解析与 Git 补丁空白检查通过。真实模型、生产安装与浏览器截图不在本次已通过范围内。

| 领域 | 已有自动化证据 |
| --- | --- |
| 身份与隔离 | 共用 Cookie、Origin/CSRF、未授权/过期、模块与模型权限、所有者404、管理接口403、最后管理员保护 |
| 费用与幂等 | UUIDv7、同键重放/冲突、报价变更、并发预占、预算缺失/不足、存储预占、实际成本与人工核对 |
| 对话 | SSE seq 去重、连接中断取快照、不重发、部分文字保留与上下文排除、scope 隔离、选中文字转新模块 |

## 后续按序执行

1. 在隔离预发布环境备份并升级账号服务和静态页面，运行构建与回归。
2. 用已有管理员账号显式初始化 AI 权限、绑定 TOTP，再设置预算与模型连接。
3. 先验证 Ollama：真实本地模型、流式/停止/断流、无云端流量、显存释放。
4. 验证 ACE-Step：申请时长、歌词/纯音乐、轮询、私有保存与 GPU 互斥。
5. 验证在线文本：报价确认、费用 usage、预算边界、网络中断与停止。
6. 验证 ElevenLabs music_v1：人声/纯音乐两种互斥请求、真实时长、二进制结果与账单核对。
7. 在桌面宽屏、1024px、390px、320px 浏览器检查导航、三栏折叠、长歌词、输入法、键盘、侧栏、播放/拖动/下载、二次验证与授权抽屉。
8. 用两名普通成员执行所有权/跨 scope 检查，两标签并发、额度仅余一次、跨午夜、取消/完成竞争、持久化保存中重启和真实断网。
9. 停服演练恢复旧数据库与文件，重放最新本地/远程删除日志，确认已删除对话和音频不会重新出现。
10. 按设计 A01–A36 记录真实证据，完成容量目标和回滚演练后再开放给成员。

每个节点型号、操作系统、显存、权重版本、在线价格来源、真实耗时与恢复结果应记录在对应环境的验收表中；不要将任何真实密钥、Cookie、验证码、私有歌词或对话提交到仓库。
