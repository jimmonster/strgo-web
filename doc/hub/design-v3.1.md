# STRGO 全站升级：设计与实现规格 v3.1

基线：2026-10-23，承接已确认的 v3.0 星环门户设计。本文与当前源码对应；v3.0 原型中的演示角色、示例任务、假进度和假作品不进入本实现。实现基于原仓库 main `e1f0f5c`，保留原生 HTML/CSS/ES Modules、Python 静态构建和既有共享账号服务。

## 1. 目标与信息架构

新增 `/hub/`，把创作、空间、社区内容和个人工作区集中到一个入口。`/home` 仍是阳光卧室。默认根首页保持经典版，同时生成 `/classic/`；以后通过构建配置切换根首页，无须迁移任务或作品。

页面顺序：星环首屏 → 生图/对话/音乐/终端 → 最近访问与收藏 → 八个空间 → 社区、作品介绍、记录、关于、实验、联系 → 个人工作区。管理员额外出现 Workflow 和管理后台。功能名称、分组、路径和权限标签来自唯一的 [功能清单](../../content/app-registry.json)，对应 [自动生成的文档表](registry.md)。

| 编号 | 页面与生产路径 | 本版行为 |
| --- | --- | --- |
| P01 | `/hub/`；选择 hub 后也为 `/` | 动态轨道球、工具入口、收藏、最近访问、空间封面 |
| P02 | `/hub/#catalog` | 按名称、英文、说明、路径搜索；分类和收藏筛选 |
| P03 | `/image-playground/`、`/ai/music/`、`/ai/chat/` | 连接原业务页面；共用深色/薄荷绿视觉和功能切换，保留参考图、灵感、音乐草稿与助手 |
| P04 | `/ai/tasks/`、`/hub/#tasks` | 当前账号的图像、音乐、对话任务，筛选、游标分页与来源操作 |
| P05 | `/ai/assets/`、`/hub/#assets` | 私有图像/音乐，预览、下载、复用、删除和图片保存重试 |
| P06 | `/hub/#settings`、`/ai/settings/` | 门户偏好与原账号/权限页分工；登录支持安全返回原路径 |
| P07 | `/admin/ai/` | 沿用模型、成员、节点、预算、审计和 MFA；Workflow 独立登录 |
| P08 | `/hub/#spaces`、`/hub/#space-room` 等 | 八张封面、空间说明和原地址；DREAMS 的八个子入口保留 |

空间封面为代码绘制的视觉示意，真实场景仍由原应用提供。三篇项目介绍、创作记录、终端 SSH、社区发帖/分类/删除/置顶、生图参数和参考图能力均保留。独立应用内部导航与视觉不在本轮重写。

## 2. 视觉与响应式

背景 `#070b10`、面板 `#0e151c`、强调色 `#79f8cb`、主文字 `#f1f7f7`，薄边框、18 px 圆角与 8 px 间距基准。完整变量见 [视觉清单](registry.md)。构建生成 `/hub/tokens.css`；门户、生图和 AI 页面引用同一套变量。共享导航样式通过外部 CSS 加载，兼容生产的 `style-src 'self'`。

桌面使用窄左栏和顶栏，主标题与轨道球左右排布；工作页面降低装饰密度。760 px 以下隐藏左栏，显示底部导航，首屏改为上下排列，工具与空间双列，目录和作品单列。任务表在自己的容器内横向滚动，页面不整体横移。交互控件保留焦点轮廓和可访问名称。

轨道为轻量 Canvas 动画；DPR 上限 1.5。用户可以关闭动画，系统减少动效偏好优先；后台隐藏、离开页面或路由切换会停止旧帧循环。Canvas 不可用时，其余入口仍可访问。不加载第三方字体或远程装饰图。

## 3. 通用能力

| 编号 | 能力 | 实际规则 |
| --- | --- | --- |
| F01 | 统一目录 | 27 个注册主入口，访客/成员显示 24 个；管理项只根据服务端身份显示 |
| F02 | 快捷搜索 | Ctrl/⌘ K、方向键、Enter、Esc；主页及已接入的共享切换器可用 |
| F03 | 收藏 | 仅存已知功能 ID，去重；存储不可用时本次页面仍可操作 |
| F04 | 最近访问 | 最多 8 项，主页显示最近 3 项；只记从门户打开的功能，无私人正文 |
| F05 | 主页模式 | 控制台/沉浸模式为浏览器偏好；不改变部署的根首页 |
| F06 | 共享身份 | 生图、AI、终端、论坛沿用共享账号；不新建账号或扩大 Cookie 域 |
| F07 | 状态表达 | 入口访问条件与在线状态分离；目录不伪造健康检查，业务沿用实际接口 |
| F08 | 任务聚合 | 图像+音乐+对话，只读索引；取消交给原 AI API |
| F09 | 作品聚合 | 图像+音乐，只读索引；下载、删除、参数复用和重试沿用原模块 |
| F10 | 偏好与降级 | 按账号隔离的本机存储；静态/减少动效；API 失败不阻断公开目录 |
| F11 | 错误与反馈 | 加载、未登录、超时、来源部分失败、无匹配结果分别呈现；提供重试 |
| F12 | 跨模块导航 | 经典主页、卧室、舞台、NEXUS 集成副本、生图、AI、论坛提供内嵌切换器；终端提供直接返回链接。音乐与生图未提交输入使用离页确认 |

搜索只查询功能清单，不搜索聊天正文、提示词、终端内容、主机或密钥。偏好键为 `strgo:hub:v1:<userId|guest>`。账号改变、页面从后台恢复或返回历史页时重新确认身份；私人列表中止旧请求，丢弃不属于当前账号的迟到响应。

独立构建的 DREAMS、POLYVERSE、MEOW、SWARMERA 与银河归档继续使用各自导航。它们都可从门户进入，但不宣称本轮为每个独立应用内部安装了相同切换器。终端不注册全局键盘快捷键，也不覆盖会话工具栏。

## 4. 任务与作品闭环

| 状态 | 含义与动作 |
| --- | --- |
| queued / running | 排队或执行中；支持时可明确确认取消 |
| saving | 保存中；不能当成生成失败重新提交 |
| save_failed | 图片已有结果但持久化失败；只重试原文件保存 |
| unknown | 原状态未知或 AI 正在核实；查看原任务，不自动生成 |
| complete | 原模块确认完成；可预览、下载、复用 |
| failed / partial | 生成失败或部分完成；显示原错误并进入原模块处理 |
| cancelling / cancelled / interrupted | 取消中、已取消、已中断；以原模块终态为准 |

不显示虚构百分比；任务统计明确限定为“本页”。列表按创建时间倒序、稳定来源 ID 排序，24 条/页，可筛来源与状态。原图像表没有更新时间，界面不编造它；AI 更新时间保留在接口数据中。任务原状态和统一状态同时保留。

作品默认仅当前账号可见，管理员的门户也不跨账号聚合。音乐保留 90 天；已删除、待删除或过期内容不进入作品列表。图像预览和音频继续使用原鉴权接口，响应不包含磁盘路径、对象键、Provider 配置、密钥或完整 AI 输入。

图像复用跳转 `?reuse=<job_id>`，加载本人原任务，填入提示词、尺寸、质量、数量；参考图须重新选择，仍需点击生成。音乐复用读取原任务参数并创建新的音乐草稿，不调用生成接口。作品删除有确认弹窗，沿用原删除流程及额度规则。可直接打开原音乐草稿继续编辑。

## 5. 实现与边界

具体文件、接口、安全边界、部署顺序和回滚见 [实现说明](implementation.md)。v3.0 的 `/api/hub/v1/*` 为规划路径；本版适配既有服务与 Nginx 规则，实际路径为 `/api/image/hub/*`。v3.0 的更新时间排序在本版改为所有来源都具备的创建时间排序。

Workflow 使用独立 host-only Cookie，在管理员入口新标签打开；不抓取其任务，不跨子域复制会话。AI 与 Workflow 的 GPU 队列没有因此合并。聚合层不改变原额度、幂等、预算、存储和任务结算策略。

生图参考图仍为最长边 4096、上传不超过 2,000,000 字节，压缩失败不提交。音乐/对话沿用原助手、表单版本校验、报价确认、SSE 和幂等提交。社区评论、编辑、站内回复通知已由 [2026-10-26 升级](../IMPECCABLE-UPGRADE.md) 实现；跨设备偏好、作者项目材料和真实四条模型链路/GPU验收仍是后续事项。

## 6. 新旧主页切换

`site.json` 默认 `"HOME_VARIANT": "classic"`，`/hub/` 和 `/classic/` 始终生成。将配置改为 `hub`，或运行 `python3 build.py --require-vendor --home-variant hub`，即可构建以门户为根首页的产物；回滚改回 `classic` 后重新构建。

原 `/#projects`、`/#stack`、`/#lab`、`/#contact` 在 hub 根首页由客户端白名单映射到 `/classic/` 的对应 hash。门户清单中的内容链接始终使用 `/classic/#...`。hash 不发送到服务器，因此不能只靠 Nginx 重定向。既有独立路由不改名。
