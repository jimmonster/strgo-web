# 统一体验与社区功能补齐

日期：2026-10-26（Asia/Shanghai）。代码基准：`2e365ed`，仓库 `jimmonster/strgo-web`。

## 本轮实现

| 需求 | 行为与源码 |
| --- | --- |
| 统一视觉 | 延续门户深色/薄荷绿方向；共享 token、字体、SVG 图标、焦点、表单、按钮、错误和浏览器表面。社区、全站后台、Workflow、AI、生图、经典主页与终端接入；视觉系统见根 `DESIGN.md`。 |
| 统一跨应用导航 | DREAMS、NEXUS、POLYVERSE、MEOW、SWARMERA、银河归档及已有卧室/舞台有统一功能切换；各世界的场景主题和自身操作保留。独立构建打包本地 `_strgo/`，不依赖另一份站点的 CSS/JS。 |
| 收藏与最近访问 | 门户外的功能切换器也可星标常用功能，并记录从此打开的入口。沿用同一份按账号隔离的本机偏好。 |
| 管理入口 | 全站管理 `/admin/` 和 AI 管理 `/admin/ai/` 分别可搜索、发现；普通会员不展示管理项。共 27 个注册入口，访客和普通会员仍为 24 个。 |
| 作者编辑 | 作者修改标题、正文和分类；提交版本号避免覆盖其他页面的更新，409 时保留输入。管理员保留治理能力，不冒充作者编辑正文。 |
| 评论 | 会员发布、分页查看，作者和管理员删除评论；纯文本显示、3000 字上限、服务端限流、CSRF 与幂等请求标识。删除帖子后评论不再可见。 |
| 回复通知 | 评论他人的帖子后通知帖子作者；私有未读计数、分页、点击打开原话题、本页标记已读。删除的帖子/评论不再出现在通知中。通知不会对外发送消息或推送。 |

`forum_comments`、`forum_notifications` 与帖子版本字段由原 `Store` 进行增量迁移；原账号、帖子、备份机制和共享会话继续工作。评论和通知随现有加密数据库备份保存。更新后需要同时部署静态文件与账号 API，终端样式需要重建其服务版本。

## Impeccable 使用方式

本轮读取了上游的技能及 extract、harden、audit、polish 和 craft-floor 指引，实际运行 `impeccable context --target src/hub/index.html`。基于已有视觉方向做归一化，未更换产品定位，也未运行交互式安装来覆盖用户环境。检测器仅作为代码检查，浏览器实际行为另行验证。

保留八个空间的艺术主题、终端键盘和视口逻辑、Workflow 独立域名会话。默认根首页仍由 `site.json` 的 `HOME_VARIANT` 决定；此次没有切换生产根首页。

## 验证记录

- `npm run build:production`：通过。
- 根 Node：`node --test tests/*.test.mjs`，106 项通过。
- 根 Python：`python3 -m unittest discover -s tests -p 'test_*.py'`，225 项通过；包含新增的 11 项讨论权限、幂等、并发、分页与备份回归。
- 独立应用：DREAMS 构建及内容/水面反射两组验收通过；NEXUS 构建及 23 项交互/几何检查通过；MEOW 构建及 32 项回归通过；POLYVERSE 的数学、状态与 DOM 验收通过；SWARMERA 的核心、场景、运行和部署回归通过。
- 终端：资源准备及既有两组前端回归通过，未修改 Rust 逻辑；本机未安装 Cargo，不将其编译或 Docker 验收写成通过。
- NEXUS 源码一致性检查、终端 token 的 `--check`、文档清单同步与 `git diff --check` 通过。发现并补齐了独立 NEXUS 源码缺少导航槽、与主站副本不一致的问题。
- 真实 Chrome + 隔离 HTTP/SQLite：作者读取帖子、查看/标记回复通知、发布评论、编辑后保留评论、站外功能切换、搜索、收藏与单次 Esc 焦点恢复通过。MEOW 的切换器能读取社区设置的同一份收藏；该浏览器未提供可用 WebGL，MEOW 使用既有静态降级，未据此声明真实 GPU 渲染已验收。
- 375 px iframe 实际检查：社区与门户无页面横向溢出，移动输入字号 16 px，底部通知入口可操作；修复了首页星环覆盖文字/按钮的问题。该检查是桌面 Chrome 的尺寸模拟，不是实体 iPhone。
- 静态 token 对比度：正文/背景 18.21:1，次要正文/抬高表面 7.80:1，主按钮文字/薄荷绿 12.44:1，错误文字/错误背景 8.13:1。这些结果只覆盖列出的静态颜色组合。
- Impeccable 上游源版本 `3671d50`；context 与一次 detector 扫描已执行。扫描报告有 54 条源码提示，以旧的小字号和眉题为主，随后已统一字号、去除冗余眉题并检查实绘；保留场景自身的空间光效和终端工具栏层级。检测器无法完整解析源码模板中的站点根资源链接，不能将其描述成完整颜色审计或零告警报告。

原始日志和扫描报告保存在本地忽略目录，最终主页截图在 `doc/hub/screenshots/impeccable-hub.jpg`。合成账号、临时数据库和 QA 接口未纳入源码，也不进入正式发布。

## 外部验收边界

本轮未发布生产，也未调用收费模型、GPU、真实 SSH 或 Docker 工作区。真实 iPhone/Safari、触摸手势及 GPU 性能仍按原清单验收；浏览器 iframe 尺寸检查只证明对应宽度的布局。作者材料、跨设备偏好同步和真实模型接入依赖原有外部条件，不用演示内容代替。
