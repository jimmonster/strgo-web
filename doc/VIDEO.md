# AI 视频操作台

入口为 /video/。操作台按三行展示左侧 9 个参考图位和右侧 3 个音频位，两个标题分别标明上传上限。每个素材位可以导入、替换、删除及点击预览，音频可试听。视频列表点击卡片后打开播放器，支持在线播放、拖动和下载。

## 设置与权限

提示词下方同一行提供生成工作流、生成时长和视频分辨率三个下拉框。时长和分辨率随所选工作流更新，使用工作流声明的选项或可枚举的整数范围。工作流未声明该参数时，下拉框显示「不适用」。需手动输入的字段和随机种子等其他参数显示在下一行。参数值按账号保存在当前浏览器。

视频列表右上方的「设置」可管理密钥、已启用工作流和成员权限，顶部「保存」和「返回」在手机上固定显示。已启用工作流以官方标题显示，对应原始 URL、工作流 ID 和提交 URL。密钥只在点击「保存」时提交，使用现有服务器加密密钥加密后落入数据库，页面只获得是否配置的状态。环境变量 AUTODL_COMFYUI_TOKEN 仍作为兼容回退。密钥、来源地址和参考素材访问令牌随每次任务加密快照，替换密钥不会改变已提交任务的查询身份。

管理员默认可生成视频并管理接口和成员权限。设置打开时隐藏成员列表，输入用户名并搜索后才显示匹配成员。勾选的待授权成员可跨搜索保留，点击顶部「保存」后授权。已授权成员会标明状态并可单独撤销。普通成员需要管理员明确授权后才能生成和上传参考素材，无法读取或修改站点接口密钥。权限、登录状态、Origin、CSRF 和素材归属均在服务端检查。撤销授权会阻止后续提交和尚未发往上游的排队任务。生成前显示付费确认，实际费用以所选 AutoDL 页面为准。

工作流目录和新增、替换操作通过现有管理员接口 `GET /api/image/admin/video/catalog` 和 `POST /api/image/admin/video/workflows` 提供。服务器核对官方标题和参数后启用工作流，可事务性替换原接口。新任务使用新接口，历史任务保留原来的标题和参数。参考图和音频按接口字段映射到固定位置，支持 ref_image_0…8、ref_audio_0…2，以及首尾帧字段。接口不支持的已选素材会阻止提交，防止静默漏传。超过 9 图或 3 音频、必填未知素材以及没有 prompt / MP4 输出的接口会拒绝启用。

## 参考素材与输出归档

图片支持 JPG、PNG、WebP，最多 1600 万像素。音频支持 MP3、WAV、FLAC、M4A / MP4，非 WAV 音频需要服务器安装 ffprobe。每份素材最多 4 MiB，同一成员的暂存素材限额为 100 MiB。导入后立即上传到账号私有缓存，服务器验证内容并加密存储；再次进入操作台会从服务器恢复 9 个图片位和 3 个音频位。替换会更新对应位置，删除会清空该位置，已提交任务所依赖的素材仍保留供任务执行。

提交给 AutoDL 的是绑定该任务和素材的临时下载 URL。访问令牌只允许读取本任务引用的特定素材，最长 23 小时，任务完成或失败后失效。公共链接不能列出素材、查看账号或读取其他文件。普通预览接口仍需账号验证。暂存素材超过一天且没有近期任务引用时会在后续上传中清理。

生成结果自动保存在 IMAGE_DATA_DIR/videos/<job-id>/<index>.mp4，默认 /var/lib/strgo-image/videos/。结果只向提交账号开放，分块输出并支持 Range。输出文件没有自动到期清理，备份时应同时备份 playground.sqlite3 与 videos/。素材与配置保存在加密数据库中，已有账号备份也会包含这些数据。

每位用户同时最多一个活动任务。同一个请求编号不会重复提交。AutoDL 提交超时或提交阶段进程中断会标为待核实，避免自动重复付费。已持有上游任务 ID 的任务恢复查询，保存失败只重试下载。单个输出最多 128 MiB，每任务最多 8 个视频，提交及保存前保留至少 512 MiB 空闲磁盘空间。

## 接口依据与部署

- https://www.autodl.art/large-model/comfyui
- https://autodl.art/docs/comfyui_api/
- 多参考图 / 音频示例 https://www.autodl.art/large-model/comfyui/minimax_h3_image_audio_to_video_v2_15s

目录元数据使用 POST /api/v1/comfyui/workflows 与 GET /api/v1/comfyui/workflows/{id}。生成和查询使用官方 ComfyUI 异步任务接口。目录字段契约沿用公开 AutoDL 集成实现，需在生产环境联调实际可访问性。参考素材使用官方工作流声明的 URL 输入格式。

按主站既有流程部署网页与账号服务，可使用 strgo deploy --skip-terminal。在 /video/#admin 保存 ComfyUI 分组令牌。通过管理员工作流接口启用支持参考图与音频的工作流后，可在操作台选择对应工作流。已在 /etc/strgo-image.env 配置 AUTODL_COMFYUI_TOKEN 的部署可继续使用原令牌。服务器必须能被 AutoDL 通过 IMAGE_PUBLIC_ORIGIN 的 HTTPS 地址访问，才能读取任务专属参考素材链接。

## 验证

python3 -m unittest tests.test_video -v 检查权限、并发幂等、输入验证、12 份参考素材映射、跨账号隔离、临时链接失效、密钥加密与任务快照、工作流替换、重启恢复及输出 Range。

根构建后执行 node tests/video-browser.mjs，验证三个下拉框的同行布局和工作流联动、按用户名搜索和保存成员授权、撤销权限、参考素材导入和预览、HTTP 上传及实际 MP4 播放。布局覆盖 1440、390 和 320 像素。浏览器测试使用模拟上游。生产令牌、目录 schema 和收费生成需在部署后联调。
