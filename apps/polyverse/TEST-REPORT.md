## 环境限制与实现范围

HTTP 服务尝试返回 `listen EPERM`；本环境不允许监听 4173/4174 端口。Chrome 单独启动也因沙箱 `setsockopt: Operation not permitted` 退出。因此未产生真实浏览器截图、真实触屏记录或 GPU 帧率数据，不宣称全项浏览器验收通过。完整脚本已交付，可在允许 Chrome 与本地 HTTP 的机器执行 `npm run test:browser`。

离线 PNG 使用真实几何和实例矩阵，但采用 CPU 投影及近似材质，只辅助检查形状和相机。它们不用于冒充网站，也不被站点加载。主网站仍使用实时 Three.js。

当前反射为镜像几何近似，未使用高开销 GPU 平面反射；自动降级为像素比与 Bloom 两步。没有音频、账号、云同步、外部社交账号或运行快照。受限街道步行通过预定义无障碍路径实现，不请求指针锁定。详细模型范围和限制见 README 与站内文档。
