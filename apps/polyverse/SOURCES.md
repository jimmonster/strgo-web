# Resources and model references

## Original project resources

All scene geometry, SVG previews, brand marks, procedural glow textures, CSS and the `Polyverse Display` lettering were created in code for this project. No external photos, reference screenshot, video, social accounts, team credentials or institution logos are used. The supplied message contained a reference-image marker but no image attachment.

`public/assets/polyverse-display.ttf` is original geometric lettering, generated by `scripts/generate-display-font.py`, dedicated under CC0 1.0. It has no third-party font outlines. System sans-serif fallbacks are resolved on the user's device; no external font files or requests are used.

Runtime geometry is created with Three.js. It is not a screenshot or background-video replacement for 3D.

## Dependencies

- Three.js 0.160.1 — MIT. Bundled locally; license copied to `dist/assets/vendor/THREE-LICENSE.txt`. Official source: https://github.com/mrdoob/three.js/tree/r160
- playwright-core 1.59.1 — Apache-2.0, development/test only. Browser executable is not bundled.
- linkedom 0.18.12 — ISC, development/test only.
- @napi-rs/canvas 0.1.97 — MIT, development/offline proof only. Not requested by the website at runtime.

Exact versions and resolved transitive dependencies are in `package-lock.json`. Upstream dependency licenses are present in installed packages after `npm ci`.

## Model and API references

- Hypercube definition and counts: https://mathworld.wolfram.com/Hypercube.html
- Einstein tensor definition: https://mathworld.wolfram.com/EinsteinTensor.html
- OrbitControls documentation: https://threejs.org/docs/pages/OrbitControls.html
- InstancedMesh documentation: https://threejs.org/docs/pages/InstancedMesh.html
- Version-pinned OrbitControls implementation, used to verify available methods in this build: https://github.com/mrdoob/three.js/blob/r160/examples/jsm/controls/OrbitControls.js
- Version-pinned InstancedMesh implementation: https://github.com/mrdoob/three.js/blob/r160/src/objects/InstancedMesh.js
- Velocity Verlet model: https://manual.gromacs.org/documentation/current/reference-manual/algorithms/molecular-dynamics.html

Model correctness is checked by the included double-precision tests. The project does not claim relativistic simulation, real astronomical units, an infinite computed fractal or actual passage into higher-dimensional space.
