# 账号终端需求文档

版本：1.1 · 日期：2026-10-22 · 状态：产品核查通过（产品代理评审，可开始开发；不代表真人产品签字或上线验收）

## 1. 目标与现状

用户需要在 STRGO 登录账号后直接使用终端，权限和 AI 生图使用同一套账号；再次访问时，在账号会话有效期内直接进入。页面采用微信式会话列表、消息气泡和输入区，可以切换多个终端，输入输出均支持选择、复制和粘贴。

现有 `apps/terminal` 已有 xterm、聊天气泡、中文输入和 SSH 沙箱，但使用独立访问口令，必须填写 SSH 地址，每页只有一个连接。此次在已有改动基础上升级，主站 AI 生图账号库作为身份来源。

## 2. 产品范围

### P0：账号与进入流程

- 未登录时显示账号、密码登录表单，沿用 AI 生图既有账号和注册邀请规则，不增加终端口令。
- 已在 AI 生图登录的用户进入终端时自动识别账号；终端登录后 AI 生图也识别同一账号。
- 共享登录的范围是同一站点、同一浏览器配置下的生图与终端入口，不承诺跨浏览器或跨设备自动登录。终端可以复用既有注册接口或提供生图注册入口；必须保留邀请码规则，不新增匿名注册或额外终端开通流程。
- 登录会话沿用 AI 生图现有 7 天有效期及服务端持久化；刷新、关闭浏览器或终端服务重启不要求重复登录。过期、主动退出或服务端撤销后需要重登。
- 7 天从原登录会话创建时起算；旧生图 Cookie 迁移到共享 Cookie 时只保留剩余有效期，不通过刷新页面或迁移无期限续期。
- 管理员与普通成员都可使用终端，终端不依赖生图 API Key、额度或图片存储配置。
- 账号登录成功后提供可直接打开的「我的终端」，不再要求用户提供 SSH 地址、密码、密钥或核对 SSH 指纹。
- 首次成功登录且没有该账号的已保存窗口时，自动建立并连接一个「我的终端」；恢复已有窗口时不自动重放连接或命令，展示清楚的「待连接／连接」入口。工作区服务不可用时仍保持账号已登录，并在当前窗口提供重试。
- 默认终端是普通用户的隔离 Linux 工作区，不能视为服务器 root shell。通过原 SSH 连接功能操作其他服务器，仍遵循目标服务器的 SSH 认证。
- 退出账号关闭本页所有连接、清除密码和临时聊天数据；账号撤销后，已连接终端在短时间内停止访问。
- 生图或终端任一入口退出，均撤销当前共享登录会话；同浏览器其他已打开页面与已有 WebSocket 在 30 秒内停止使用该会话。换账号前清除前账号的聊天、密码、草稿和活动连接，窗口元数据按账号分别读取。这里的退出不等同于退出其他设备；修改密码沿用生图现有撤销全部旧会话的规则。

### P0：多窗口与聊天界面

- 桌面左侧显示终端会话列表，右侧显示选中会话；手机通过会话入口切换列表与聊天区域。
- 支持新建、切换、重命名、关闭和重新连接终端，显示连接中、可用、已断开状态和未读提示。
- 切换终端不关闭其他连接；每个窗口独立保存连接、xterm 缓冲区、聊天记录、草稿、显示模式和滚动位置，不能把 A 窗口输出或草稿送到 B。
- 默认最多保留 8 个窗口，后端全局并发限额沿用配置；达到上限明确提示，失败不丢草稿。
- 「窗口数量」与「服务端活动连接数量」分别计数：恢复的离线窗口不占后端并发；本页 8 个窗口已满时可关闭后再建，后端全局配额已满时允许保留窗口与草稿等待重试。已断开窗口不自动重连。
- 关闭有连接的窗口需确认；重新连接只新建连接，不自动重放命令。
- 右侧绿色气泡展示发送内容，左侧气泡展示实时输出。长输出、中文、emoji、ANSI 控制序列和进度刷新正常显示。
- 普通工作区文件按账号隔离并持久保存；同一账号的窗口可访问自己的工作目录。断开清理会话容器，重新打开保留工作区文件。
- 页面刷新后恢复该账号的窗口名称和非敏感连接配置，显示为待重新连接，不承诺恢复已退出进程；长任务需要使用受支持的持久会话工具。
- 账号工作区仅承诺工作目录文件持久化，不承诺容器进程、后台任务或完整系统状态持久化。沿用服务配置的连接最长时限（默认 1 小时），界面显示连接计时及超时原因；SSH 长任务可使用目标服务器已安装的 tmux 等工具，本地工作区不得宣传未提供的进程恢复能力。
- 当前页聊天与终端缓冲区有明确内存上限；可沿用现有约 120 条气泡、4,000 行终端回滚及单条约 300 行／48,000 字符的限制。发生裁剪时显示「较早输出已省略」，导出标明只包含当前保留文本，不得把被裁剪的日志宣称为完整历史。

### P0：编辑、复制与粘贴

- 消息支持鼠标选择、手机长按选择与单条复制；支持复制选中的终端文本和导出当前聊天文本。
- 输入区支持中文输入法、多行编辑、系统复制粘贴和粘贴按钮；粘贴不自动执行。
- 聊天模式下粘贴只进入编辑区。原始终端模式下，包含换行的剪贴板内容必须回到编辑区待确认发送，或采用明确的逐次发送确认；不得通过粘贴按钮或系统粘贴绕过此规则。单行原始终端粘贴可以写入当前命令行但不附加回车。
- 普通回车换行，发送按钮或 Ctrl/Cmd+Enter 执行；输入法选词期间不能误发送。
- 已发送命令可重新放回编辑器，必须再次发送才执行。
- SSH 密码采用显式密码模式，密码不显示在聊天气泡、历史导出、浏览器存储或应用日志中。
- 密码模式默认关闭自动补全，不创建明文命令气泡；发送后、切换窗口、断开或退出时清空密码字段，不恢复为草稿。必须测试拆包回显的脱敏；界面说明在 SSH 请求密码时启用密码模式，普通命令模式输入的任意文本无法自动识别为秘密。
- 提供中断、Tab、Esc、方向键及原始终端视图，兼容 vim/top 等交互程序。复制操作不能误发 Ctrl+C。
- 剪贴板接口不可用或权限被拒绝时仍可使用原生选择和系统粘贴，并提供可操作提示。

### P1：体验与异常

- 会话搜索、最新输出跳转、字号调整、清屏、连接状态、空状态与操作反馈。
- 适配桌面与 320px 起的手机宽度、软键盘、安全区；页面无横向溢出，输入框与发送按钮始终可达。
- 网络断开保留当前页输出和非密码草稿，显示重新连接入口；不静默重新执行命令。
- 禁用存储、API 服务异常、资源加载失败、并发已满和会话过期均有明确提示。
- 文本以纯文本渲染，服务器输出不能注入网页脚本。

## 3. 技术边界

- 复用 `image_service` 的账号、密码校验、SQLite 会话、CSRF 与登录限流；增加跨终端与生图共享的 HttpOnly Cookie，并兼容原生图登录的迁移。
- Rust 网页服务只向固定回环地址的账号服务核实身份；浏览器不能自行指定账号 ID 或代替其他用户创建工作区。
- WebSocket 建连验证同源和账号，并周期复核账号；依赖故障时停止授权，不能降级为匿名或旧口令。
- 身份服务仅返回终端所需的用户 ID、用户名、角色、CSRF 和有效期等最小信息；不得让终端会话检查依赖生图 API Key、生成额度或远端图片存储健康状态。共享 Cookie 保持 HttpOnly、SameSite=Strict 与生产 Secure，原登录、改密、退出的 CSRF 与限流均须回归。
- 复用现有沙箱代理与资源上限；账号工作区使用稳定且经校验的账号标识派生命名卷，浏览器不能选择宿主机目录，不开放 Docker socket。
- 默认工作区是普通 UID 的基础 Linux shell，默认使用无网络容器；只开放已提供的基础命令，不承诺 sudo、任意软件安装、Python／Node 开发环境或联网能力。现有 Docker bridge 的禁容器互访不等于禁止访问宿主机与云元数据；不得把原 SSH 地址验证误用为本地 shell 的网络保护。未来联网能力需另行定义边界。
- 持久目录不能沿用「断开即清除全部数据」的旧宣传；清屏、关闭窗口、断开连接都不删除账号文件。持久卷容量需有明确治理方案：部署说明给出容量监测、满盘提示及账号卷清理步骤，并明确普通 Docker 命名卷无硬配额的限制；未经实测不得声称有每账号磁盘硬限额。真实部署应按可用磁盘配置限制或运维监测。
- SSH 模式保留现有地址验证和独立容器；服务级 SSH 私钥仅限管理员，不能让普通账号继承共享的服务器登录权限。
- 不保存账号密码、SSH 密码或聊天正文至 localStorage。仅按账号保存窗口元数据；导出由用户手动发起。
- 不自动部署到生产、重启线上服务或影响正在使用的 SSH 会话。提供构建、检查、升级和回滚说明，并明确本地验证与线上验证的边界。

## 4. 验收标准

1. 用既有 AI 生图账号登录终端成功；错误密码、过期与撤销账号拒绝访问。
2. 生图已登录进入终端无需再输入密码；刷新和终端服务重启后仍可使用有效账号会话。
3. 普通成员无需生图配置可直接打开工作区，管理员和普通成员工作区互相隔离。
4. 同时创建至少 3 个窗口，交替输出，切换时连接不断、输出不串、草稿不串；关闭只影响目标窗口。
5. 输入中文、emoji、多行命令与大段粘贴，输入法期间无误执行；单条复制、选择复制和导出文本完整。
6. SSH 密码不出现在气泡、导出和浏览器持久存储；切换窗口、退出或断开不遗留密码。
7. 账号退出或撤销使已有连接停止；恶意账号 ID、跨源 WebSocket 和异常输入被拒绝。
8. 普通工作区写文件后关闭并重开文件仍在；其他账号无法访问该目录。
9. 断网、限额、存储禁用、剪贴板拒绝可恢复；不会自动重放命令。
10. 桌面与手机浏览器检查通过，无主要遮挡和横向溢出；保留原 SSH 功能回归检查。
11. 旧生图登录迁移后仅保留原有效期，任一入口退出在 30 秒内使另一个入口与全部当前共享会话连接停止；修改密码使旧会话失效。
12. 初次登录直接获得可输入的工作区；恢复页面不重放命令，工作区故障、资源限额和最长连接时限均有明确状态。
13. 原始终端模式粘贴含换行命令不自动执行，聊天与终端选区复制不触发中断；受保护密码的拆包回显不会进入气泡与导出。
14. 默认工作区无法联网、访问宿主机接口或挂载 Docker socket，普通成员不能继承服务级 SSH 私钥；关闭工作区保留文件、关闭 SSH 容器清除临时内容的差异可验证。
15. 达到聊天／终端回滚上限有裁剪提示，导出含范围说明；禁用浏览器存储仍可登录、建窗、连接和编辑，刷新不恢复窗口时给出说明。

## 5. 执行顺序与交付

1. 输出本需求文档。
2. 由独立产品核查任务审核流程、范围、权限与验收，结论记录到 `PRODUCT-REVIEW.md`；修订通过后开始开发。
3. 实现共享账号与可直接打开的隔离工作区。
4. 实现会话列表、多窗口隔离、复制粘贴与异常恢复。
5. 完成自动化测试、浏览器检查和产品复核；根据发现修复。
6. 交付源码、需求/核查文档、验证记录及升级说明。无法在当前环境验证的真实容器或线上环节须如实标记，不作为已通过项。
7. 产品核查通过仅确认需求具备开发条件。交付时产品代理依据上述验收矩阵复核实现，区分「已通过」「代码核对／模拟通过」与「待真实环境验证」；真实 Docker、跨账号隔离、主站共享 Cookie 与 SSH 登录未经实测时，不得标记为生产验收通过。
