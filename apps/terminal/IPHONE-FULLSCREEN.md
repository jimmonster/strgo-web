# iPhone 全屏终端

手机进入已登录的终端后，隐藏主工作台标题栏、会话标题栏、品牌、状态栏、计时和底部说明。默认仅显示聊天/终端输出，以及一行命令编辑区。

- 输入行左侧「☰」打开窗口列表，可以切换、新建、连接、改名、导出、清屏和关闭窗口；手机列表底部保留退出账号。
- 输入行「＋」临时展开聊天/原始终端切换、密码模式、快捷键、复制粘贴和编辑展开功能，再点一次收起。工具默认收起。
- 原始终端模式保留底部窗口、工具入口、中文编辑框与发送按钮，不再用空标题栏占高度。
- 外层页面用 `visualViewport.height` 和 `offsetTop` 跟随 Safari 的可见区域；子会话只使用 iframe 已分配的高度，避免软键盘高度被重复扣除。
- 输入框限制为可见会话高度的一部分，长文本在输入框内滚动；普通输入字号保持 16px，减少 Safari 自动缩放。键盘弹起时移除底部 Home 指示器预留，键盘关闭后恢复安全区。
- 启用「添加到主屏幕」的 iOS 独立显示元数据。从 Safari 添加到主屏幕后打开可减少浏览器自身的地址栏占用；网页不能强制隐藏 Safari 系统栏。

## 验证

29 项子会话交互测试、9 项多窗口 DOM 测试通过。新增用例覆盖 Safari 可见高度和偏移、iframe 不重复扣减、长输入限高、无标题栏时的窗口入口、原始终端操作保留。资源路由与语法检查通过，release 构建已准备。

浏览器脚本已增加 310px 可见区域、78px Safari 视口偏移的布局检查，同时要求键盘弹起后输出仍占大部分可见高度。当前环境实际启动 Chromium 时仍因 `setsockopt: Operation not permitted` 退出，尚未完成真实 Safari/iPhone 的画面验收。

## 安装

页面资源嵌入 Rust 二进制，单独刷新 CSS 文件不会更新线上界面。已准备的新编译件需更新服务后生效：

```bash
bash /root/strgo-web/apps/terminal/update-account.sh
```

本次会话仍受 socket/systemd 权限限制，不能声称已安装。安装完成后，在手机刷新 `/terminal/`。如果使用添加到主屏幕的入口，关闭旧窗口再重新打开。
